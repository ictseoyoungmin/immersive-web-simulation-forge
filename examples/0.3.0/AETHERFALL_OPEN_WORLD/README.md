# AETHERFALL — The Open Sky

A self-contained procedural open-world web experience built with raw WebGL 2, DOM HUD, and Web Audio.

## Run

Open `index.html` in a current Chrome or Edge browser. Hardware acceleration and headphones are recommended.

## Controls

- `W A S D`: glide
- Mouse movement after click, or mouse drag: look
- `Space` / `C`: rise / descend
- `Shift`: boost
- `Q`: deep scan
- `E`: attune a nearby beacon
- `V`: cycle world phase
- `H`: cinematic HUD

## Goal

Find and attune the three dormant beacons. The canonical aether field drives terrain veins, ocean response, atmosphere, the Meridian Ring, hidden structures, telemetry, and sound.

## Notes

The renderer adapts internal resolution and ray-march quality to sustained frame rate. No network requests or external assets are required.
