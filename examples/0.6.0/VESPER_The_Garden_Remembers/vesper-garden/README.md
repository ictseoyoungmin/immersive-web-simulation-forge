# VESPER: The Garden Remembers

당신이 깨운 모든 꽃이 바람과 음악으로 남아, 마지막 귀환로를 만드는 1인용 브라우저 게임입니다.

## 실행

`index.html`을 Chrome, Edge, Firefox, Safari 같은 최신 브라우저에서 여세요. 설치·계정·서버·인터넷 연결은 필요하지 않습니다. 브라우저가 로컬 파일의 오디오 재생을 묻는다면 허용한 뒤 **새로운 밤 시작**을 누르세요.

## 한 번의 밤

- 밤의 공식 시간창은 `15:00`입니다.
- 여섯 꽃을 원하는 순서로 깨웁니다.
- 꽃 주위를 표시된 방향으로 돌아 깨운 뒤, 그 꽃이 만든 바람을 타고 네 개의 공명 문 안에서 빛을 맞춥니다.
- 두 번째와 네 번째 목소리 뒤에는 중앙 심장으로 돌아와 화음을 묶습니다.
- 여섯 바람이 모두 남은 정원을 통과해 심장으로 귀환하면, 활성화 순서가 마지막 음악과 정원 서명이 됩니다.
- 시간이 끝나도 **잔광 속에서 계속하기**로 현재 정원을 복구할 수 있습니다.

첫 플레이는 탐색과 적응을 포함해 약 8–15분을 목표로 설계했습니다. 숙련자는 더 일찍 끝낼 수 있으며, 사람 대상 플레이타임·재미 검증은 아직 수행되지 않았습니다.

## 조작

| 행동 | 키보드 | 포인터 / 터치 |
|---|---|---|
| 이동 | `WASD` 또는 방향키 | 화면을 누른 채 목표 방향으로 드래그 / 왼쪽 스틱 |
| FOCUS | `Space` | 마우스 우클릭 유지 / 오른쪽 FOCUS 버튼 |
| 일시정지 | `Esc` 또는 `P` | 우측 상단 일시정지 버튼 |
| 마지막 안전 지점에서 재형성 | `R` | 일시정지 메뉴의 다시 시작 |

FOCUS는 파동을 없애지 않습니다. 꽃의 힘을 잠시 덜 받으며 공명 문 안에 머물게 해주고, 사용하지 않을 때 천천히 회복합니다.

## 접근성과 복구

- 음악과 소리 끄기
- 움직임 줄이기
- 목표·가시 대비 강화
- 자동 / 높음 / 절전 시각 품질
- 키보드, 마우스, 터치 경로
- 5초 간격과 주요 사건 시 자동 저장
- 일시정지, 마지막 안전 지점 재형성, 시간 종료 후 잔광 계속하기

## 정직한 범위

이 게임의 규칙과 파동은 `visual-concept` 수준의 결정론적 아케이드 모델입니다. 실제 유체역학, 식물학 또는 음향학을 모사하지 않습니다. 기본 구성은 데스크톱 가로 화면에 최적화되어 있으며, 작은 가로 터치 화면에는 축약 HUD를 제공합니다. 절차적 오디오는 브라우저에 따라 미세하게 다르게 들릴 수 있습니다.

## 구성

- `index.html` — 실행 진입점
- `src/` — 게임 규칙, 렌더러, 오디오, UI
- `assets/` — 로컬 한글 글꼴
- `VALIDATION.json` — 완료된 브라우저·규칙·성능 검증 요약
- `preview.webp` — 대표 장면
