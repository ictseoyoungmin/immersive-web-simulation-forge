# Pixel Minions: Room Explorer — Phase 1

## Launch

Double-click `Pixel_Minions_Room_Explorer_Phase1.html` in a current desktop Chrome, Edge, or Firefox browser. The renderer is embedded; no internet connection, local HTTP server, or installation is required.

## Controls

- **WASD** move
- **Mouse** look; click the world to capture the pointer
- **Space** jump
- **Shift** sprint
- **Mouse wheel** camera distance
- **R** respawn at the latest checkpoint
- **P** toggle the live tuning panel
- **Esc** release pointer lock

## Included systems

A 20 × 20 × 8 m oversized room, tiny third-person hero, 120 Hz fixed-step parkour physics, raycast grounding, desk and bookshelf routes, instanced room clutter and collectibles, warm shadowed lighting, dust particles, adaptive resolution, live parameters, checkpoints, and lifecycle cleanup.

See `VALIDATION.json` for browser and gameplay evidence.
